# Customer Churn Analysis (Excel Project)

## Overview
This project analyzes customer churn behavior in a telecom dataset using Microsoft Excel.

The goal is to identify patterns that cause customers to leave the service.

## Dataset
Telco Customer Churn dataset containing 7000+ customer records.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Conditional Formatting
- Data Visualization

## Key Analysis
- Contract Type vs Churn
- Monthly Charges vs Churn
- Tenure vs Churn
- Payment Method vs Churn

## Key Insights
- Month-to-month contracts have the highest churn rate 

- Long-term contracts significantly reduce churn, New Customers retaintion rate - aproximately 50%

- higher monthly charges churn more but premium prize payer churn rates are low.
